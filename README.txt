TaterPeeler website - made by Andres Campos

Upload everything in this folder (keep the folders as they are) to any static web host,
for example Cloudflare Pages or GitHub Pages. Nothing else to set up.

  index.html          the game
  download/           the Download page, with the Mac, Windows, iPad and Cydia files
                      (big files are split into 8 MB pieces; the page joins them)

The site has to be opened from its web address (https://...) for downloads to work.
