# TaterPeeler credits
# Edit this file on GitHub and the website shows the new credits the next time it's opened.
# The apps (iPhone, iPad, Android, Mac, Windows) pick it up the next time they're built.
#
# How it works:
#   - Each line is one line of the credits (Settings, at the very bottom).
#   - Lines starting with # are notes like these and don't show up.
#   - An empty line adds a little space.
#   - A link: the words, then a | , then the web address. For example:
#       Original track | https://tokyomusicwalker.bandcamp.com/track/echoes-in-blue
#     Links on lines right after each other sit side by side.
